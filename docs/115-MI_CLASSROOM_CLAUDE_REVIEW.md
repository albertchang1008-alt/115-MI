## 3. 權限與資料安全（程式碼審查）

- **五個課堂互動 API** 都先限定課程為 `115-1-MI-國考精準對焦`，再經既有的 `access()` 驗證：
  - 教師必須在該課程的 `teacherIds` 內；
  - 學生必須是已發布課程、啟用中的名冊成員，且班級在已發布的班級清單內。
- 學生不能呼叫教師 API。開放與結束作答、統計報表、個人紀錄都是 `teacherOnly`。
- **作答**：
  - 在 transaction 內檢查是否已作答，每人每輪只計一份，重送不加票；
  - 交卷與教師收票的先後由 transaction 決定；
  - 同時只能開一輪；答案依題型逐一驗證；每輪上限 200 人，文件大小有界。
- **學生端顯示**：開放期間只回傳題目，結束後才回傳統計。有姓名、學號的個人紀錄只有教師 API 拿得到。
- **正式前後測**：
  - 學生拿到的是 `publicExamQuestion`，沒有答案和解析，選項逐人洗牌；
  - 成績由後端依私有答案批改；本班後測全部結束後才能公布；
  - 前後測題目會從一般練習題庫移出，`assertPracticeBank` 防止繞道取得。
- **授課簡報**：只有該課程教師拿得到；學生的課堂更新 API 只回傳本班可見內容。

## 4. 非阻擋建議（下次改版處理即可）

1. **課程代碼寫死**：`115-1-MI-國考精準對焦` 寫在 `shared/classroom.ts`、`functions/src/teaching.ts`、`src/App.tsx` 三處。下學期換課程代碼時，這些功能會全部失效。建議改成課程設定，或集中成一個常數。
2. **反思題改成選項後，研究資料變少了**：原本「原本以為／現在知道」的概念改變文字已經不見。等 1.8.0 開放式反思活動（規格已交辦）完成後，建議再加回文字題。
3. **c1-toxin 理由選項 3**「尚未對照毒素的來源與作用」語意不清楚，建議改成「還不確定毒素從哪裡來」。
4. **測試對外部字型有依賴**：`src/style.css` 的 `@import` 讓瀏覽器測試依賴外部網路，建議測試注入 CSS 時先去掉 `@import`，避免沒有網路時誤報失敗。
