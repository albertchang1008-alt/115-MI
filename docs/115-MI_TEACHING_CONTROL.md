# 115-MI 授課控制台

2026-10-12；版本1.7.1。教師指定單螢幕全螢幕簡報。

## 使用方式
1. 教師登入115-MI，選課程「115-1 國考精準對焦輔導課程」，左側「授課控制台」。
2. 「簡報播放」讀取核可的38頁教師投影片。可選頁或用上一頁／下一頁；全螢幕後方向鍵、PageUp／PageDown或空白換頁，B暫時黑屏；Esc或「回控制台」退出。全螢幕不顯示講者備註。
3. 「學生學習進度」控制整個單元：移到「目前學習」開放，移到「尚未開放」隱藏。控制套用本課程各班，不刪學生紀錄。此區「本次考試結束」是單元移至歷史，正式測驗收卷另在前測／後測控制。
4. 「前測／後測」沿用正式場次、手動開放／結束／公布、報表與CSV；不需日期時間，個別8分鐘，公布前不傳答案給學生。翻投影片不會自動開考或調整單元。
5. 「學生完成度」沿用完成度看板，按更新取得各班與個別學生最近儲存的進度。

## 權限與範圍
- 教師簡報HTML、答案頁與備註只存Firebase私有courses/<MI課程>/teacherAssets/presentation，由getTeachingDeck驗證教師及課程管理權限後提供；不放Git、public或前端JS。只供指定MI課程。
- 投影片內嵌1920×1080沙盒iframe，禁止scripts／表單／導覽及外部網路，只允許內嵌樣式與data圖片。文字與圖片沿用核可投影片，僅抽出aside成獨立備註。
- 學生getClassroomCourse只回本人班級已發布且可見的單元，不含簡報／備註。頁面每15秒及重新聚焦時更新課程；單元被隱藏時退出該單元一般練習並回首頁。後端getBank仍以當下發布與班級權限檢查。
- 無網路時保留目前頁面；已開啟的外部教材頁面不受遠端單元隱藏控制，不能替學生強制換頁。正式測驗不受簡報頁碼控制。
- 單螢幕回控制台時，投影會顯示同一畫面。查看講者備註／學生成績時，請先使用教室投影設備的暫停／黑屏功能；簡報內B黑屏不會遮住退出後的控制台。
