# 115-MI 課堂互動：狀態列、綁定投影片、倒數計時（2026-10-13 教師選定，Claude 撰寫規格）

## 問題

教師上課時不知道目前開了哪個互動：上一題可能忘了關，或在錯的頁面開了互動。

## 教師選定的三項改善

### 1. 常駐狀態列（教師全螢幕投影的每一頁都看得到）

- 位置固定在教師畫面的一角，不遮住投影片的主要內容。黑屏時一起隱藏。
- **有互動開放中**：綠色底，顯示以下內容與按鈕：
  - 互動名稱（例：討論點1 內／外毒素）與第幾輪
  - 已收人數／參與班級名冊人數
  - 剩餘時間（有設倒數時）或已開時間（沒設時）
  - 按鈕：「結束作答」「＋30 秒」（＋30 秒只在有倒數時出現）
- **沒有開放中的互動**：灰色底，只寫「目前沒有開放的互動」。
- 資料沿用既有的 2 秒更新，不新增輪詢頻率。
- 投影畫面只顯示人數，不顯示姓名、學號。

### 2. 互動綁在投影片上

- **只有 12 個互動頁**會出現互動控制區，其他頁不出現「開放」按鈕。
- 互動頁上顯示「本頁互動」的狀態：
  - 未開放：顯示 [開放作答]，旁邊可選倒數時間（見第 3 項）。
  - 開放中：顯示 [結束作答]。
  - 已結束：顯示第 N 輪，以及 [顯示結果]、[再投一輪]。
- **別頁的互動還開著時**，在本頁按「開放作答」會跳出確認：
  > 「（互動名稱）」仍在開放中（已收 X 人）。要結束它並開放本頁嗎？
  > [結束並開放本頁] [取消]
  - 按下確認後，後端在**同一個 transaction**裡先結束舊的一輪、再開新的一輪，不會出現兩輪同時開放。
- 確認框必須做在頁面內，不可用 `alert` 或 `confirm`。
- **翻頁仍然不會自動開放或結束互動**（維持既有決定）。

### 3. 倒數計時（新增，取代原本「不限時」）

- 開放作答時可選倒數時間：不限時、30 秒、60 秒、90 秒、2 分鐘、3 分鐘。預設 60 秒，可以在畫面上改。
- **截止時間以後端為準**：
  - 開放時，後端在這一輪寫入 `deadlineAt`（伺服器時間＋秒數）；不限時就不寫這個欄位。
  - `submitClassroomInteraction` 在 transaction 內檢查。超過 `deadlineAt` 的送出一律拒絕，訊息為「時間到，作答已截止」。給網路延遲 3 秒寬限。
  - 「＋30 秒」：教師 API 延長 `deadlineAt`，只能延長開放中的那一輪。
- **時間到時**：後端停止收件，狀態列變成橘色「時間到」。這一輪**不會自動結束**，由教師按「結束作答」或「顯示結果」。這樣可以保留「時間到但還想多給一點時間」的彈性。
- **學生手機**：
  - 開放期間顯示倒數。剩 10 秒時數字變色提醒。
  - 時間到後顯示「時間到，等待老師公布結果」，已填但沒送出的選項保留在畫面上，但不能再送出。
  - 已送出的照舊鎖定。
- **時鐘校正**：前端用 API 回傳的伺服器時間校正倒數，不依賴手機時鐘。

- 只改 MI：`.worktrees/site-115-MI`，分支 `codex/115-mi-assessments`。
- 不動正式前後測、題庫、名冊、成績，也不動 AP2。

- 既有互動題目內容與統計規則不變。這次只改：

  - 截止時間檢查；
  - 教師與學生的畫面。
- 舊的一輪資料若沒有 `deadlineAt`，一律視為不限時，不得出錯。
